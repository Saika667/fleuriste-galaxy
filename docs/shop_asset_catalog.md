# Shop — catalogue des modèles actuels

89 références distinctes, deux vues isolées par référence et trois vues en contexte. Les numéros incluent variantes et sous-ensembles ; les objets répétés sont regroupés.

Les images isolent la géométrie du jeu dans un studio Godot. Elles ne sont pas des concepts générés. Les fleurs natives sont intégrées aussi aux objets du jeu via leurs constructeurs partagés. Le présentoir est garni pour la présentation ; les vases de stock reflètent le stock de la session de référence.

Régénération : scène `scenes/shop/shot_shop_catalog.tscn`, arguments `-- shop_catalog nomerge`, puis `tools/package_shop_catalog.py`. Le mode catalogue extrait les géométries avant fusion, les capture dans un SubViewport propre et ne modifie pas la sauvegarde joueur. Les croquis imprimés des affiches, les feuilles vertes du lierre et la plante carnivore spécifique restent leurs modèles existants. Les primitives de fleurs présentes dans la rue ou les bâtiments voisins ne font pas partie de cette passe sur le shop.
